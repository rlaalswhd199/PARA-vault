# Papers Index

읽은 논문들의 마스터 인덱스. Claude `paper-reading-note` 스킬로 자동 갱신 가능.

## 사용 방법

1. arXiv 링크 또는 PDF를 Claude에게 전달하며 "논문 정리해줘" 요청
2. Claude가 `Papers/` 안에 구조화된 노트(`Paper_저자YY_제목.md`) 생성
3. 본 인덱스에 한 줄 추가
